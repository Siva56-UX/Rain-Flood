# การตรวจสอบหน้าประชาชนและพยากรณ์ 7 วัน

## ทดสอบอัตโนมัติ

`npm run test:resident` ครอบคลุม:

- วันตามเวลาไทย เที่ยงคืน ข้ามเดือนและปี และพยากรณ์วันพรุ่งนี้ถึงอีก 7 วัน
- ค่า null, string, ลบ, Infinity, probability เกินช่วง, หน่วยไม่ตรง, วันซ้ำ และวันขาด
- ช่วง ensemble ที่ผิดลำดับและการเทียบแนวโน้มเมื่อข้อมูลไม่ครบ
- แหล่งฝนและแหล่งน้ำล้มเหลวแยกกัน, validation อำเภอ, cache รายอำเภอ, รวมคำขอพร้อมกัน
- ข้อมูลเก่าเกิน 6 ชั่วโมงและการเปิดหน้าค้างข้ามวัน
- ประกาศผิดพื้นที่, หมดอายุ, อนาคต, URL ปลอม, ระดับไม่รองรับ และ ID ซ้ำ
- feed ไม่ตั้งค่า/โหลดล้มเหลวไม่กลายเป็นสถานะปลอดภัย

Fixture อยู่ใน test เท่านั้น ไม่ถูก import โดยโค้ด production

## ขอบเขตการตรวจหน้าจอ

ผลตรวจเมื่อ 25 กันยายน 2569: unit tests 10/10 ผ่าน; TypeScript และ production build ผ่าน; ทดลอง production HTTP server ในเครื่องได้หน้าแรก 200, อำเภอไม่ถูกต้อง 400, ประกาศที่ไม่ตั้งค่าเป็น `unconfigured` และ API ฝน/น้ำจริงคืนข้อมูลครบ 7 วันของอำเภอเมืองสิงห์บุรี (`available` ทั้งสองแหล่ง, `floodRisk: unknown`) ครั้งหนึ่งแหล่งข้อมูลโหลดไม่สำเร็จและแสดง `unavailable` ตามที่ออกแบบ การลองตรวจครั้งถัดไปสำเร็จ ไม่มีข้อมูลจำลองใช้แทน

ทดสอบ TypeScript และ production build แล้ว แต่ยังไม่ได้ยืนยันการแสดงผลและการกดใช้งานด้วยเบราว์เซอร์: หน้าทดสอบเชื่อมต่อไม่ได้ในสภาพแวดล้อมนี้ จึงไม่อ้างว่าผ่านการทดสอบบนมือถือ, โปรแกรมอ่านหน้าจอ หรือเสียงภาษาไทยจริง

## ก่อนเปิดให้ประชาชนใช้

ทดสอบกับผู้สูงวัยจริงอย่างน้อย 3–5 คน บนโทรศัพท์ที่ใช้ประจำ ให้ทำเองโดยไม่บอกขั้นตอน:

1. เลือกอำเภอของตนเอง และกลับมาเปิดใหม่เพื่อดูว่าอำเภอยังถูกต้อง
2. บอกได้ว่าข้อมูลล่าสุดดึงเมื่อไร และแยกโอกาสฝนจากโอกาสน้ำท่วม
3. หาวันที่คาดว่าฝนมากที่สุด และเข้าใจเมื่อบางวันไม่มีข้อมูล
4. ขยายตัวหนังสือ, ฟังเสียง, หยุดเสียง, เปลี่ยนอำเภอขณะเสียงอ่านอยู่
5. เปิดประกาศต้นฉบับและหาเบอร์ขอความช่วยเหลือ (ไม่โทรจริงเพื่อทดสอบ)

ตรวจที่ 320, 390, 768 และ 1280 CSS px; ขยาย browser 200%; ใช้คีย์บอร์ด, TalkBack/VoiceOver; ตรวจ focus, contrast, ข้อความไม่ล้น และการกดพลาดระหว่างปุ่ม

ทดสอบเสียงบน Android/iPhone จริงทั้งมีและไม่มีเสียงภาษาไทย ห้ามถือว่าเสียงบนเครื่องพัฒนาจะเหมือนอุปกรณ์ผู้ใช้

ตรวจ localStorage ถูกบล็อก, อินเทอร์เน็ตหลุด, ฝนล้มเหลวอย่างเดียว, น้ำล้มเหลวอย่างเดียว, ข้อมูลบางวันหาย, เปิดค้างข้ามเที่ยงคืนไทย, เปิดหลายหน้าพร้อมกัน และประกาศหมดอายุขณะเปิดหน้า

ต้องยืนยันพิกัดตัวแทนกับผู้เชี่ยวชาญพื้นที่ และยืนยันแหล่งประกาศจริงก่อนใช้คำเตือนเพื่อการอพยพ รุ่นนี้ไม่มีผลพยากรณ์น้ำท่วมรายบ้านที่ผ่านการปรับเทียบ
